## Architecture
- **main() 是启动骨架，业务编排在 `AppController`**（TODO#3 外移，2026-10-25）：`main.cpp`（43 行）只做 `initLogFile` → messageHandler → `QApplication` → 锁文件 → Fusion → `ConfigManager config` → `AppController controller(config)` → `controller.startup()` → `app.exec()`；`src/ui/appcontroller.h/.cpp` 持有窗口 map、全局热键、设置对话框生命周期、托盘接线、两条重载路径（`startup()` 内部顺序敏感：首启模态 → `createWindows` → `applySettingsHotkey` → 托盘）
- **Single instance**: `QLockFile` at `%TEMP%/<user>_Stickers Manager.lock` (Release, unchanged) or `%TEMP%/<user>_Stickers Manager_debug.lock` (Debug build, `SM_TEST_BUILD` → `main.cpp:20-33`) — debug and installed release can run side by side
- **Config** (`[EXE_DIR]/.stickersmanager/`, relative to exe):
  - `config.json`: `{"default":{ui,behavior,window,performance},"libraries":[{id,path,hotkey,enabled,settings:{}}]}` — no version field; `id` is the **order marker** (0..n-1, contiguous): `getLibraries()` sorts by id (`configmanager.cpp:196-217`), missing ids (legacy) get array position, drag-reorder in the Libraries tab renumbers ids; `enabled` = **hotkey switch only** ("Enable Hotkey" checkbox) — does NOT affect window/tray/menu/double-click target/storage stats, only global-hotkey registration and hotkey-conflict computation
  - `settings.json`: `doubleClickTarget` (default `"settings"`; `"first-library"`/library id string; legacy dirName/path values still matched as fallback, `appcontroller.cpp:280-341`), `searchDelayMs` (300), `thumbnailCacheSize` (200), `checkForUpdatesOnStartup` (true), `startWithWindows` (false), `logLevel` (default `""` = unset → build-derived via `defaultLogLevel()`: console build = `Debug`, else `Warning`; value = `"Debug"`/`"Info"`/`"Warning"`/`"Critical"`/`"Fatal"`; Base tab combo shows the **effective** level and only persists values differing from the build default — choosing the default clears the key), `openSettingsHotkey` (default `"Ctrl+I"`, record-mode string like `"Ctrl+Shift+E"`, `""` = unbound), `openSettingsHotkeyEnabled` (default `true`)
  - Defaults are **single-sourced**: every default value lives only in `hardDefaults()` (`configmanager.cpp:10`); `loadConfig()` merges the loaded `default` block against it (`mergeDefaults`, in memory only, never written back — missing or type-corrupted keys get the hard default), and getters take **no fallback argument**. Change a default in `hardDefaults()` (or `defaultSettings()` for settings.json), nowhere else
  - `recent_<md5(libraryPath)>.json`: per-library **recently-used** list `{"entries":[{path,time}]}` (storage capped 100, newest first, stale files pruned on load); written by `RecentUsageStore` (`src/core/recentusage.cpp`) on double-click copy; shown as the first "Recent" pseudo-category in `MainWindow::populateCategories()` — **hidden entirely when empty**, created live on first use (`onStickerDoubleClicked` → `refreshRecentButton()` returns false → repopulate), and hidden entirely when disabled via `recentEnabled` (`populateCategories` gate + `showCategory("Recent")` guard + record skipped in `onStickerDoubleClicked`); right-click on it shows a "Clear Recent Records" menu (`onCategoryContextMenuRequested`, `CustomMenu` style, `RecentUsageStore::clear()` deletes the file, then repopulate hides it); its preview icon is a clock (`setShowClock`), drawn from `:/assets/Clock - 24x24.png` tinted via `SourceIn` (`clockicon.cpp` `makeClockIcon()`); display cap = `recentLimit` (`default.ui`, default 100, per-library override) applied in `RecentUsageStore::paths()`; count label refreshed live via `MainWindow::refreshRecentButton()`
- **No auto-save** — config written on explicit `saveConfig()` / `saveSettings()` only (Settings "Save & Reload", `settingsdialog.cpp:66-67`), plus the fallback folder-picker save in `mainwindow.cpp:173` when a window has an empty path
- **First-launch** — if no library with existing path, modal `SettingsDialog tmpDlg.exec()` (`appcontroller.cpp:44-58`) blocks before any window/tray
- **Multi-window**: one `MainWindow` per library with non-empty path (regardless of hotkey switch); title `"Stickers Manager - <dirName>"` (`appcontroller.cpp:79`)
- **Scanning** (`stickerlibrary.cpp`): **immediate subdirectories** only are categories (non-recursive); `isPreviewFile()` (name starts with `.preview` or contains `.preview.`) files excluded from scan/search/stats (`fsutil.hpp:26`); search matches against a prebuilt lowercase-filename index; the directory walk is shared — `fsutil::forEachStickerFile` (template) drives both `StickerLibrary::scanLibrary()` and the library structure stats in `librarysettingspage.cpp`
- **Global hotkeys**: Win32 `SetWindowsHookEx(WH_KEYBOARD_LL)` via `GlobalInputListener`; key↔string mapping + `ShortcutCompare::compareShortcutKeys` in `convertcodetostring.hpp`; handler = `AppController::onGlobalKeyReleased`（`appcontroller.cpp:117`）; **settings hotkey** `openSettingsHotkey` (default Ctrl+I, toggles the Settings dialog) is checked **first** in the `keyReleased` handler (before the `hotkeyToWindow` loop), and the listener starts when the window map is **non-empty OR the settings hotkey is enabled** (`applySettingsHotkey()` refreshes both after every `loadSettings()`); while the Base page records a hotkey (`SettingsDialog::isHotkeyRecording()`) the global handler returns early — prevents pressing a registered hotkey from toggling a window/dialog mid-record; during the first-launch modal dialog `toggleSettings` no-ops (`QApplication::activeModalWidget()`)
- **Two runtime reload paths** (don't confuse them):
  - `fullReload` (`appcontroller.cpp:176`) — tray **Rescan**: reloads config, removes stale windows, creates new ones, rescans all libs via `reloadLibrary()`
  - `applyChanges` (`appcontroller.cpp:191`) — settings dialog `applied` signal: updates per-window `LibraryConfig` + reapplies settings, **no rescan**
- **Image loading**: `stb_image` (primary), `QImageReader` (fallback) in `imageloader.cpp`
- **Async thumbnails**: `QtConcurrent` + `QThreadPool` via `AsyncThumbnailLoader`; LRU `QCache` in `ThumbnailCache`
- **Window hide releases memory**（量化后落地，`mainwindow.cpp` `hideEvent`）: every cell `setInViewport(false)`（复用 scroll-out 卸 GIF QMovie）+ `ThumbnailCache::clear()`；**不** `clearStickerCells()` —— cells keep `m_currentPixmap` → re-show has zero placeholder flash；`showEvent` calls `updateCellVisibility()` to restore in-viewport animations；`logMemoryState()` emits `[mem]` Info lines on hide/show/`decay+Xs`（hide 后 1/5/15/60s 采样，判回落 vs 钉死），字段含 `mCreated/mDestroyed`（QMovie 全局原子计数，`stickercell.cpp`，差值>0 即泄漏）与 `privMB/wsMB`（`processMemoryUsage()` → `GetProcessMemoryInfo`，需 `<windows.h>`+`<psapi.h>`）。**量化结论：后台内存大头是 GIF `QMovie`（`loadAnimation` 把整个 GIF 文件读进 QBuffer + 解码帧，单部 1.2~2.1MB），缩略图缓存仅 0.9~4.9MB** —— GIF 类目实测 105.7MB → 隐藏 35.2MB（旧版 150MB 不回落）；诊断埋点：`ThumbnailCache::stats()`、`StickerCell::pixmapBytes()/isAnimationLoaded()`、`CategoryButton::pixmapBytes()`
- **QMovie 生命周期红线**：`m_movie` 与 QBuffer 互为 parent（环）且**不挂在 cell 下** → `StickerCell` 析构**必须走 `unloadAnimation()`**（`delete m_movie` 断环），绝不能只 `stop()` —— 曾因析构只 `stop()` 导致切类目/滚动剪枝 `delete cell` 整环泄漏（5 轮实验 leaked=96、priv 线性 +60MB/轮、隐藏后 315MB 平线；修复后 leaked=0、浏览稳定 ~64MB、隐藏回落 34MB，详见 `docs/.ai/changelog.md` [2026-10-25]）
- **Startup update check**: `UpdateChecker` hits GitHub API (`apiReleasesUrl()`), gated by `checkForUpdatesOnStartup`

## Override system
- `getEffectiveXxx(lib)` — checks `lib.settings[cat][key]` via `effVal()`, falls back to `default[cat][key]` (normalized at load, see Config), then `hardDefaults()`
- **MainWindow caches** its effective settings in `EffectiveSettings m_eff` (struct in `mainwindow.h`), refreshed by `refreshEffectiveSettings()` on ctor, `applySettings`, and `updateLibraryConfig` — the scroll hot path (`updateVisibleCells`) reads `m_eff`, so a **new setting must be added to both `EffectiveSettings` and `refreshEffectiveSettings()`**, then read via `m_eff.xxx` in hot paths
- 0 = "not overridden" for numeric; "General"/"On"/"Off" for booleans
- `getDefaultXxx()` reads from `default{}` (set by General tab)
- Tag toggles (4 keys in `default.behavior`, default true): `showStickerName`, `showStickerSize`, `showCategoryName`, `showCategoryCount` (General tab + per-library combos)
- `recentLimit` (`default.ui`, default 100, per-library numeric override, 0 = not overridden): recent display cap
- `recentEnabled` (`default.ui`, default true, per-library bool override via General/On/Off combo in the UI overrides group): master switch for the Recent feature — when off (effective), the Recent category is hidden (even with existing records), recording is skipped on double-click copy, and `showCategory("Recent")` is a no-op; records file is kept so re-enabling restores the category

## Conventions
- **All source globbed**: new files need re-run `cmake ..` to be picked up
- **No `.ui` files**: `AUTOUIC ON` but all UI in C++ code; `CMAKE_AUTOMOC` + `AUTORCC` also ON
- **Style**: Fusion (`main.cpp:37-39`)
- **Logging** (`log.hpp` decl + `log.cpp` impl, refactored on Pelr's logger): writes to `log/log.log` relative to working dir, truncated on each start, format `[yyyy-MM-dd hh:mm:ss.zzz] [Level]: msg`, UTF-8; `messageHandler` is **always installed** (`main.cpp`) — console builds write console + file, non-console builds file only (`#ifdef CONSOLE` gates only the console half); console output uses **`WriteConsoleW` (UTF-16, bypasses the console codepage → no Chinese mojibake)**, falling back to UTF-8 bytes on `stderr` when redirected; single `extern g_logLevel/g_logMutex` globals (locked `set/getLogLevel()` — never touch them directly); default level = `defaultLogLevel()` (console build `Debug`, else `Warning`), overridden by `settings.json` `logLevel` applied via `AppController::applyLogLevel()` after every `loadSettings()` (startup + `fullReload`/`applyChanges` + first-launch dialog); the `AppController` ctor (`appcontroller.cpp:14`) prints a Chinese startup line `StickersManager 启动 — 日志级别: X` right after applying it
- **Version**: `appinfo.h:7` — `AppInfo::version()` returns `"v2.10.0"` (**carries the `v` prefix**, unlike `pkg.iss`), manual bump only on release; must match `CHANGELOG.md` top + `pkg.iss` or `scripts/check_version.ps1` fails
- **About page**: version comparison strips `v` prefix, parses `major.minor.patch` numerically (`UpdateChecker::compareVersions`)
- **Header-only utils**: `static` functions in `launcher.hpp` / `fsutil.hpp` (one copy per TU); logging is the exception — `log.hpp` only declares, `log.cpp` defines (shared singletons). `launch()` opens paths/URLs via `QtConcurrent::run` + `QDesktopServices`; `notifyTray()` marshals tray messages from worker threads to the GUI thread (`QueuedConnection`)
- **Tests**: only manual acceptance scripts in `tests/` (`test_structure_hint.ps1` 31 / `test_addlib.ps1` 29 / `test_reload_path.ps1` 19 / `test_preview.ps1` 14 assertions) — `powershell.exe` 5.1 + UIA driving the real exe, **self-contained and fully in-project** (no private dirs, no `%TEMP%`): `tests/make_fixtures.ps1` is the single entry that *generates* `tests/fixtures/` on demand (System.Drawing, ~1s, **gitignored — never committed**; runnable standalone via `-File`, and dot-sourced by `tests/seed.ps1` so every test run auto-ensures fixtures — `lib_a`/`lib_b` 30 stickers each, `lib_ok`/`lib_deep`/`lib_empty` structural variants, `lib_nope` intentionally absent); `seed.ps1` also backs up `build/.stickersmanager/*.json`, writes a seed config pointing at those fixtures (`lib_a` id0/`Ctrl+Shift+E`, `lib_b` id2/`Shift+Ctrl+D`, `logLevel=Debug`, fixture-keyed `recent_*.json` purged — else the app boots into Recent and grid-coordinate assertions break), restore-or-delete in teardown; scratch (dead paths, stderr capture) lives in `build/tests_tmp/`; every `tests/*.ps1` **must keep a UTF-8 BOM** (PS 5.1 reads BOM-less files as ANSI → parse crashes; re-add after editing, recipe in `tests/README.md`), usage in `tests/README.md` (paths derive from script location, run from repo root); **no unit tests / CI / linters**; packaging via `pkg.iss` (Inno Setup); release artifacts (`StickersManager_<ver>.exe/.7z`) at repo root are **gitignored** (`*.exe`/`*.7z`) — local only, never committed
